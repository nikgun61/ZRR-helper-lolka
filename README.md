
# ZRR Helper Bot

Вспомогательный бот для автоматизации публикации сообщений в каналах ZRR.

На текущем этапе бот умеет работать с каналами типа `vs`: определяет текущий день недели, удаляет сообщение предыдущего дня и публикует подготовленный текст на текущий день.

## Возможности

-   подключение к Lolka через `lolka.py`;
-   загрузка списка каналов из `channels.json`;
-   выбор обработчика в зависимости от типа канала;
-   определение текущего дня недели в часовом поясе ZRR;
-   загрузка сообщений из Markdown-файлов;
-   удаление сообщения предыдущего дня;
-   защита от повторной публикации сообщения текущего дня;
-   логирование работы в консоль и файл `logs/bot.log`.

### `main.py`

Точка входа в приложение.

Отвечает за:
-   настройку логирования;
-   загрузку переменных окружения;
-   загрузку списка каналов;
-   определение текущего дня недели;
-   создание и подключение клиента;
-   запуск нужного обработчика для каждого канала.

### `client.py`

Содержит класс `LolkaClient`, являющийся обёрткой над `lolka.Client`.

Реализует основные операции с Lolka:
-   подключение клиента;
-   получение истории канала;  
-   отправку сообщений;
-   удаление сообщений.  

### `bot.py`

Содержит логику обработки каналов.

Для типа `vs` выполняется следующий алгоритм:
1.  Загружается содержимое файла предыдущего дня.
2.  В истории канала ищется сообщение с таким содержимым.
3.  Если сообщение найдено — оно удаляется.
4.  Загружается содержимое файла текущего дня.
5.  Проверяется последнее сообщение канала.    
6.  Если сообщение текущего дня ещё не опубликовано — оно отправляется.
    

### `utils/file_utils.py`

Вспомогательные функции для работы с файлами:
-   поиск файла по префиксу;
-   чтение текстового файла;
-   поиск и чтение файла одной операцией;
-   загрузка конфигурации каналов из `channels.json`.

### `utils/datetime_utils.py`

Работа со временем ZRR.

Часовой пояс задаётся через:

```python
ZRR_TIMEZONE = timezone(timedelta(hours=-2))
```

День недели возвращается в стандартном формате Python:

```text
0 — понедельник
1 — вторник
2 — среда
3 — четверг
4 — пятница
5 — суббота
6 — воскресенье
```

### `utils/logging_utils.py`

Настраивает логирование приложения.

Логи одновременно выводятся:
-   в консоль;
-   в `logs/bot.log`.

Формат записи:
```text
2026-08-30 12:00:00 | INFO     | bot | VS processing started: channel_id=123 weekday=6
```

## Установка

Требуется Python 3.12 или совместимая версия.

Клонировать репозиторий:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd zrr_helper_lolka

```

Создать виртуальное окружение:
```bash
python -m venv .venv
```

Активировать его:

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:
```powershell
.venv\Scripts\activate
```

Установить зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

### Переменные окружения

В корне проекта необходимо создать файл `.env`:
```env
TOKEN=токен_бота
```

Файл `.env` не должен попадать в Git.

### Настройка каналов

Создайте в корне проекта файл `channels.json`.

Пример:
```json
[
  {
    "id": 112233445566,
    "type": "vs",
    "comment": "Тестовый канал"
  }
]
```

Поля:
-   `id` — ID канала;
-   `type` — тип обработчика канала;
-   `comment` — произвольный комментарий для удобства.

Сейчас поддерживается тип:
```text
vs
```

`channels.json` не хранится в Git, поэтому его необходимо создать отдельно после клонирования проекта.

## Контент

Контент для обработчика `vs` находится в директории:
```text
vs/
```

Файл для каждого дня недели начинается с номера соответствующего дня:
```text
0_monday.md
1_tuesday.md
2_wednesday.md
3_thursday.md
4_friday.md
5_saturday.md
6_sunday.md
```

При поиске используется именно префикс файла, поэтому название после номера может быть изменено.

Например, для понедельника допустим файл:
```text
0_any_name.md
```

В директории должен существовать ровно один файл с соответствующим префиксом.

Если файл не найден, приложение завершится с ошибкой.

Если найдено несколько файлов с одинаковым префиксом, приложение также завершится с ошибкой.

Содержимое Markdown-файла отправляется в канал как текст сообщения.

## Запуск

Из корневой директории проекта:
```bash
python main.py
```

При запуске бот:

1.  загружает конфигурацию;
    
2.  определяет текущий день недели ZRR;
    
3.  подключается к Lolka;
    
4.  последовательно обрабатывает настроенные каналы;
    
5.  удаляет сообщение предыдущего дня;
    
6.  при необходимости публикует сообщение текущего дня;
    
7.  отключается после завершения обработки.

Логи сохраняются в:
```text
logs/bot.log
```

Если директория `logs` отсутствует, она будет создана автоматически.

Пример:
```text

2026-08-30 12:00:01 | INFO     | client | Client is ready
```

## Добавление нового типа канала

Тип обработчика определяется полем `type` в `channels.json`.

Сейчас в `main.py` реализован обработчик:
```python
if channel_type == "vs":
    await vs(
        client=client,
        channel_id=channel_id,
        weekday=weekday,
    )
```

Для добавления нового типа канала необходимо:
1.  создать соответствующий обработчик;
2.  добавить необходимые файлы контента или конфигурацию;
3.  добавить обработку нового значения `type` в `main.py`;
4.  указать новый тип для нужного канала в `channels.json`.
