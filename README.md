# ZRR Helper Bot

Вспомогательный бот для автоматизации публикации сообщений в каналах ZRR.

Сейчас бот работает с каналами типа `vs`: определяет текущий день недели по времени ZRR, удаляет своё сообщение предыдущего дня и публикует текст на текущий день.

## Структура проекта

```
zrr_helper_lolka/
├── main.py            # точка входа: запуск, обход каналов, код возврата
├── bot.py             # обработчики каналов (сейчас — vs)
├── client.py          # LolkaClient — обёртка над lolka.Client
├── config.py          # пути проекта и загрузка настроек (.env)
├── channels.json      # список каналов (не хранится в Git)
├── requirements.txt
├── utils/
│   ├── datetime_utils.py
│   ├── file_utils.py
│   └── logging_utils.py
├── vs/                # контент по дням недели: 0_*.md … 6_*.md
└── logs/
    └── bot.log
```

Все пути считаются от корня проекта, поэтому бота можно запускать из любой директории (например, из cron).

## Установка

Требуется Python 3.12 или совместимая версия.

```
git clone <URL_РЕПОЗИТОРИЯ>
cd zrr_helper_lolka
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

Файл `.env` в корне проекта (в Git не попадает):

```
TOKEN=токен_бота
```

Файл `channels.json` в корне проекта (в Git не попадает):

```json
[
  {
    "id": 112233445566,
    "type": "vs",
    "comment": "Тестовый канал"
  }
]
```

Поля: `id` — ID канала, `type` — тип обработчика (сейчас только `vs`), `comment` — необязательный комментарий. Если в файле указан неизвестный тип, бот завершится с ошибкой ещё до подключения.

## Контент

Файлы для обработчика `vs` лежат в директории `vs/`. Имя файла начинается с номера дня недели и подчёркивания (`0_` — понедельник, …, `6_` — воскресенье); остальная часть имени может быть любой, например `0_any_name.md`.

Для каждого дня должен быть ровно один файл. Если файла нет, он пуст или найдено несколько файлов с одним префиксом, бот завершится с ошибкой до подключения к Lolka.

Содержимое файла отправляется в канал как текст сообщения; пробелы и переводы строк по краям обрезаются.

## Как работает обработчик `vs`

1. Загружаются тексты текущего и предыдущего дня.
2. Загружаются последние 100 сообщений канала; учитываются только сообщения самого бота.
3. Если среди них есть сообщение с текстом предыдущего дня — оно удаляется (если тексты дней совпадают, удаление пропускается).
4. Если сообщения с текстом текущего дня ещё нет — оно публикуется.

## Запуск

```
python main.py
```

Ошибка в одном канале логируется и не мешает обработке остальных. Код возврата: `0` — всё успешно, `1` — был сбой приложения или хотя бы одного канала.

## Логирование

Логи пишутся в консоль и в `logs/bot.log` (директория создаётся автоматически):

```
2026-08-30 12:00:00 | INFO     | main | Application started
2026-08-30 12:00:01 | INFO     | bot | VS processing started: channel_id=123 weekday=6
```

## Добавление нового типа канала

1. Написать обработчик в `bot.py` (или в отдельном модуле).
2. Добавить тип в `SUPPORTED_TYPES` и ветку вызова обработчика в `run()` в `main.py`.
3. Указать новый тип у нужного канала в `channels.json`.

## Зависимости

`python-dotenv`, `lolka.py` — полный список в `requirements.txt`.
